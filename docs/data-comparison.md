Generated by `npm run compare:csv` from `C:/Users/metat/Downloads/Cambodia_Mountain-coords.csv`.

> This reflects the dataset **after** the safe merge. See `docs/safe-merge-report.md` for what was changed.

## Method

- CSV rows are matched to `public/mountains-kh.json` by normalized name (diacritics, punctuation and case removed), then confirmed by distance ≤ 5 km.
- If no name match exists, a coordinate-only match ≤ 1 km is reported as a naming difference (usually transliteration variants).
- Elevation is compared against the app value shown to users: `elev` when present, otherwise `dem`. Differences ≤ 5 m are ignored.
- The comparison is read-only: no data file is modified.

## Recommendations

1. **Do not bulk-overwrite elevations.** The two sources use different elevation models; most gaps are under 20 m and are not necessarily errors.
2. **Verify the few large outliers** (> 100 m difference) against a surveyed or authoritative source before editing the dataset.
3. **Use the CSV as an alias source** — it supplies 60+ alternative spellings that could be added to the `alt` field to improve search.
4. **Add the 40 unmatched entries** only after confirming they are real, distinct features; several are Thai/Lao/Vietnamese names for border peaks.
5. **Keep the app’s wider scope** — islands, passes and ridges make up most of the features missing from the CSV.
